## Purpose

定义本期在移除登录界面前提下的会话接入行为——前端以固定 dev 身份静默获取后端所需凭据,保证核心功能在无认证 UI 下仍可调用受保护接口。

## ADDED Requirements

### Requirement: 静默获取会话凭据

在无登录界面的前提下,前端 SHALL 在启动时以预置的开发身份自动获取后端所需的会话凭据(token),并在后续 API 调用中附带该凭据。此过程 MUST 对用户不可见,不呈现任何认证表单。

#### Scenario: 启动即就绪

- **WHEN** 用户打开应用
- **THEN** 前端在后台完成凭据获取
- **AND** 用户无需任何操作即可访问受保护的审计功能

### Requirement: 凭据失效的静默恢复

当会话凭据失效或缺失时,前端 SHALL 自动尝试重新静默获取,而非跳转到登录界面。

#### Scenario: 凭据失效重取

- **WHEN** 受保护接口因凭据失效返回未授权
- **THEN** 前端自动重新静默获取凭据并重试,不呈现登录界面
