## Purpose

报告页信息层级与导航能力：为长审计报告提供锚点/侧栏目录与区块深链，使用户能快速定位所需区块，降低在长页面中滚动查找的成本。

## ADDED Requirements

### Requirement: 报告区块目录导航

系统 SHALL 在审计报告页提供区块目录（侧栏或锚点导航），列出报告的主要区块（结论、指标、攻击矩阵、场景对比、防护方案、攻击路径、证据链）。点击目录项 MUST 将视图滚动定位到对应区块。

#### Scenario: 点击目录项定位区块

- **WHEN** 用户在报告页点击目录中的"攻击路径"
- **THEN** 视图滚动到攻击路径区块并高亮当前项

#### Scenario: 目录反映当前滚动位置

- **WHEN** 用户滚动报告页
- **THEN** 目录中对应当前可视区块的项被标记为激活状态

### Requirement: 报告区块深链

系统 SHALL 支持通过 URL 哈希深链直达报告的指定区块。打开带区块锚点的链接 MUST 自动滚动到该区块。

#### Scenario: 深链直达指定区块

- **WHEN** 用户打开形如 `#/audits/<id>#remediation` 的链接
- **THEN** 报告页加载后自动滚动定位到防护方案区块

### Requirement: 移动端导航降级

在移动端（≤720px）目录 SHALL 以可折叠形式呈现，不遮挡报告内容，且不破坏既有底部主导航。

#### Scenario: 移动端目录可折叠

- **WHEN** 在 390px 视口打开报告页
- **THEN** 区块目录以折叠入口呈现，展开后可选择区块，收起后不占据主内容区
