## MODIFIED Requirements

### Requirement: 攻击集版本数据驱动发现

系统 SHALL 以数据驱动方式发现并加载已登记的攻击集版本或测试套件，新增一个合法攻击集版本或用户自定义测试套件 MUST 不需要修改代码中的固定枚举。系统 MUST 仅接受已登记且校验通过的版本或套件，拒绝未知、冲突或结构非法的版本或套件。

#### Scenario: 加载已登记的新攻击集版本

- **WHEN** 资源目录中存在一个已登记的攻击集版本并被请求
- **THEN** 系统成功加载该版本用于攻击生成

#### Scenario: 拒绝未登记版本

- **WHEN** 请求一个未登记的攻击集版本
- **THEN** 系统拒绝并返回明确错误，不静默回退

#### Scenario: 加载用户自定义测试套件

- **WHEN** 用户通过控制台创建一个校验通过的自定义测试套件
- **THEN** 套件发现接口返回该自定义套件
- **AND** 发起检测时可选择并运行该套件

#### Scenario: 拒绝结构非法的自定义套件

- **WHEN** 用户提交的自定义测试流程无法生成合法 ageval 数据集结构
- **THEN** 系统拒绝保存并返回明确错误
- **AND** 发起检测时不可选择该非法套件
