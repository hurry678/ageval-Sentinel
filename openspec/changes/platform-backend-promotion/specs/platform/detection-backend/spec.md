## Purpose

定义平台对外唯一后端的交付契约：它如何被启动与发现、如何自描述能力、如何接入任意被测 Agent、如何从数据集发现检测套件、以及如何委托执行并暴露可回放证据。使「通用型 Agent 检测平台」这一主张有可验证的规格背书，而不是仅存在于未记录的实现里。

## ADDED Requirements

### Requirement: 单一交付后端与可重复的启动入口

平台 SHALL 只通过一个后端对外提供检测能力。该后端 MUST 具备仓库内可重复执行的启动方式，且该方式 MUST NOT 依赖开发者个人机器的绝对路径、个人虚拟环境位置或单一操作系统。项目文档 MUST 把这一入口作为唯一上手路径。仓库中的其他 HTTP 审计接口 SHALL NOT 被描述或提供为交付入口，其代码 MAY 保留并作为库被复用。

#### Scenario: 新开发者按文档启动平台

- **WHEN** 一名此前未接触本仓库的开发者只按项目文档的启动步骤操作
- **THEN** 后端与控制台成功启动，且健康检查返回可用状态
- **AND** 所执行的启动脚本中不包含任何开发者个人路径或个人虚拟环境位置

#### Scenario: 文档不再指向已退役的入口

- **WHEN** 读者在项目文档中查找如何启动平台
- **THEN** 只能找到唯一后端的启动方式
- **AND** 找不到把已退役界面或库层审计接口当作交付入口的指引

### Requirement: 后端能力自描述

后端 SHALL 提供一个健康检查响应，其中至少包含平台版本、支持的目标接入方式集合、可用的内置被测 Agent 集合、以及检测流水线的节点定义。前端与外部调用方 MUST 能仅凭该响应获得这些集合，不得在自身代码中硬编码同一集合的副本。

#### Scenario: 前端从健康检查获得可选项

- **WHEN** 控制台需要渲染「目标接入方式」与「内置被测 Agent」的可选项
- **THEN** 这些取值来自健康检查响应
- **AND** 前端代码中不存在与后端重复的同名硬编码集合

#### Scenario: 新增内置 Agent 后自描述自动更新

- **WHEN** 在唯一登记处新增一个内置被测 Agent
- **THEN** 健康检查响应中的内置 Agent 集合自动包含它，无需改动健康检查的实现

### Requirement: 内置被测 Agent 的单一登记

内置被测 Agent 的合法集合 SHALL 只在一处登记。取值校验、对外暴露的可选项清单、以及运行时的实例化 MUST 全部从该登记派生，不得在多处重复同一集合或以 if/else 逐个分派。新增一个内置被测 Agent MUST 只需修改该登记一处。

#### Scenario: 拒绝未登记的内置 Agent

- **WHEN** 调用方提交一个未登记的内置被测 Agent 标识作为检测目标
- **THEN** 请求被拒绝，并在错误信息中列出当前合法取值
- **AND** 该合法取值列表与登记处一致

#### Scenario: 新增内置 Agent 只改一处

- **WHEN** 在登记处新增一个内置被测 Agent 条目
- **THEN** 该标识立即通过目标校验、出现在对外可选项清单中、并可被实例化执行
- **AND** 无需改动校验逻辑、清单暴露或实例化分派中的任何其他位置

### Requirement: 检测套件的数据驱动发现

检测套件 SHALL 由工作区内的数据集清单发现。新增一份第三方数据集 MUST NOT 需要修改代码或登记白名单。当数据集声明了平台未登记的场景分类时，系统 MUST 降级为「该套件的攻击面覆盖信息缺失」，而 MUST NOT 拒绝该套件或中断请求。

#### Scenario: 放入新数据集即可被检测

- **WHEN** 在工作区放入一份符合清单格式且包含用例目录的第三方数据集
- **THEN** 该数据集出现在套件列表中并可被选为检测对象
- **AND** 未修改任何代码或白名单

#### Scenario: 未登记的场景分类降级而非报错

- **WHEN** 某数据集的用例声明了平台未登记的场景分类
- **THEN** 套件仍可正常列出与运行
- **AND** 其攻击面覆盖显示为缺失，而非返回错误

### Requirement: 任意 OpenAI 兼容端点作为检测目标

后端 SHALL 接受任意 OpenAI 兼容的模型端点作为检测目标，登记一个目标 MUST 只需要一条目标条目而不必改动任何数据集文件。凭据 MUST 以环境变量名的形式引用，MUST NOT 以明文存储于目标条目或出现在接口响应中。回环地址端点 MAY 免凭据登记。

#### Scenario: 登记外部端点目标

- **WHEN** 提交一个包含模型名、`http(s)` 完整地址与凭据环境变量名的目标
- **THEN** 该目标被接受并可发起检测
- **AND** 目标条目与接口响应中均不含凭据明文

#### Scenario: 非回环端点必须声明凭据来源

- **WHEN** 提交一个非回环地址的端点目标但未声明凭据环境变量名
- **THEN** 请求被拒绝，并提示应填写环境变量名而非明文密钥

#### Scenario: 回环端点免凭据

- **WHEN** 提交一个回环地址的端点目标且未声明凭据环境变量名
- **THEN** 该目标被接受

### Requirement: 执行委托与运行可观测

后端 SHALL 把用例执行委托给外部评测引擎，自身只负责编排与状态归集。对每次运行，后端 MUST 提供运行状态查询、增量事件流、以及逐用例的可回放证据；对进行中的运行 MUST 支持取消。运行记录 MUST 在进程重启后仍可读取。

#### Scenario: 观察进行中的运行

- **WHEN** 调用方发起一次检测并订阅其事件流
- **THEN** 收到按序号递增的增量事件，并在运行结束时收到结束标记

#### Scenario: 取消进行中的运行

- **WHEN** 对一个进行中的运行请求取消
- **THEN** 该运行停止执行，且其状态反映为已取消

#### Scenario: 重启后仍可读取历史运行

- **WHEN** 后端进程重启后查询一次已完成运行
- **THEN** 该运行的状态、逐用例结果与可回放证据仍可读取
